# Projeto - Rede de Pequena Empresa

## Objetivo

Criar uma rede simples utilizando o Cisco Packet Tracer.

## Equipamentos

- 1 Roteador Cisco 2811
- 1 Switch Cisco 2960
- 2 Computadores

## Configuração

- Endereçamento IPv4
- Gateway padrão
- Teste de conectividade com ping

## Tecnologias

- Cisco Packet Tracer
- IPv4
- Redes de Computadores
